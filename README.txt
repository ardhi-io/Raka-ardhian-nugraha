RAKA ARDHIAN NUGRAHA — PERSONAL WEBSITE
========================================

CARA MENJALANKAN
1. Extract ZIP ini.
2. Buka folder hasil extract.
3. Klik dua kali index.html, atau jalankan dengan Live Server di VS Code.

GANTI FOTO
Simpan foto milik Raka ke folder assets/images dengan nama berikut:
- profile.jpg       : foto utama di beranda (portrait)
- project-01.jpg    : preview proyek 1
- project-02.jpg    : preview proyek 2
- project-03.jpg    : preview proyek 3
- gallery-01.jpg    : foto galeri 1
- gallery-02.jpg    : foto galeri 2
- gallery-03.jpg    : foto galeri 3
- gallery-04.jpg    : foto galeri 4

Format yang disarankan JPG/JPEG. Kalau belum ada fotonya, placeholder otomatis tetap tampil.
Kalau foto kamu PNG, ubah ekstensi/nama file di index.html juga.

GANTI MUSIK
1. Masukkan file musik ke assets/music/.
2. Namai file itu your-song.mp3.
3. Tombol musik di kanan bawah akan memutarnya setelah diklik.
Catatan: browser tidak mengizinkan musik autoplay sebelum pengunjung berinteraksi.

PERSONALISASI SEBELUM DIPUBLIKASIKAN
- Cari hello@example.com di index.html lalu ganti dengan email Raka.
- Ganti tautan Instagram, GitHub, dan LinkedIn yang masih href="#".
- Ganti judul dan deskripsi tiga proyek contoh dengan proyek asli.
- Isi tahun, detail pengalaman kerja (jika ingin), dan informasi lain sesuai fakta.
- Cek kembali penyebutan program studi/STEI-K agar sesuai nama resmi yang ingin ditampilkan.

STRUKTUR
index.html       halaman utama dan seluruh konten
style.css        desain, layout, responsive mobile
script.js        navigasi mobile, animasi reveal, pemutar musik
assets/images/   tempat foto
assets/music/    tempat file musik

Website ini dibuat sebagai satu halaman panjang dengan navigasi ke setiap bagian.
